# Documentación de referencia (`00 - docref`)

Documentación estable, histórico y material auxiliar del proyecto KC868A2.  
Las carpetas `docs/vX.Y/` documentan el **alcance de cada rama**; aquí vive lo atemporal o legado.

## Mapa

| Carpeta | Contenido |
|---------|-----------|
| [referencia/](referencia/) | Guías vigentes: hardware, API, MQTT, web, compilación, OTA, integración |
| [versiones/](versiones/) | Release notes y README de versiones de firmware |
| [archivo/](archivo/) | Histórico de mejoras, análisis y notas sueltas de la raíz |
| [sketches/](sketches/) | Sketches Arduino / versiones previas (no PlatformIO activo) |
| [csv/](csv/) | CSV de prueba e importación de ejemplos |
